## 화면 검증 중 발견해 함께 수정한 동작

1. 메모의 높이가 입력값 변경 때만 계산돼, 창 너비를 줄이면 줄이 늘어나도 높이가
   그대로였다. 메모 박스에 ResizeObserver를 연결했다. 같은 글을 입력한 상태에서
   1920→375px로 바꾸면 높이가 54→90px로 갱신되고 불필요한 내부 스크롤이 생기지 않는다.
2. 저장 성공 시 `saving`을 해제하지 않아, Cache Components가 보존한 상세 페이지로
   돌아왔을 때 저장·삭제가 계속 비활성 상태였다. `finally`에서 저장 상태를 해제한다.
   저장→목록→상세 재진입 후 두 버튼 활성화 및 실제 삭제를 확인했다.
3. 긴 메모의 첫 글자가 원본보다 7px 위에 있었다. 넘치는 메모에만 내부 위 여백 7px를
   적용했다. 모바일 첫 글자 y=549px로 원본과 일치한다. 짧은 메모의 가운데 배치는 유지한다.
